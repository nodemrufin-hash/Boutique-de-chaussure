# Shoe Store Website

This project is a modern shoe store website built with Next.js, React, and TypeScript. The goal is to create a clear and responsive shopping experience where users can browse shoes, view product details, use a cart, and contact the store.

## Project Overview

The website presents a small online shoe shop. It includes a home page, a product catalog, product detail pages, a shopping cart, and a contact page. The interface is designed to work well on desktop, tablet, and mobile screens.

This project can be used to show frontend development skills, component organization, responsive design, and basic e-commerce features.

## Main Features

- Home page with presentation sections
- Product catalog
- Product detail page
- Shopping cart
- Contact page
- Language switch between French and English
- Light and dark theme support
- Responsive design
- Reusable React components
- PWA support with manifest and service worker

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- EmailJS
- i18next
- Serwist
- ESLint

## Project Structure

```txt
src/
  app/                 Application pages and routes
  components/          Reusable React components
  config/              Website configuration
  context/             React context files
  data/                Local product data
  lib/                 Application helper logic
  locales/             French and English translations
  providers/           Global providers
  types/               TypeScript types
  utils/               Utility files

public/
  icons/               Public icons
  images/              Product images
```

## Installation

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Run the production version:

```bash
npm run start
```

Run the linter:

```bash
npm run lint
```

This project was created to practice and demonstrate web development skills with a real e-commerce example. It focuses on user interface, responsive layout, component-based development, and a simple shopping experience.
